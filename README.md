## GitHub Pages
1. Create a new GitHub repository.
2. Upload every file and the `assets` folder from this project.
3. Go to Settings → Pages.
4. Select Deploy from a branch → `main` → `/root`.
5. Save and wait for GitHub Pages to publish.

The order form opens WhatsApp with the visitor's entered details. Ratings are immediately rendered in the Reviews section and stored in that visitor's browser with localStorage. Because GitHub Pages is static, this browser storage is not shared between different visitors. A shared public rating system for all visitors requires a small database/backend (for example Firebase or Supabase).
